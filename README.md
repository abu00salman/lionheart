# أكاديمية قلب الأسد — Lion Heart Academy

الموقع الرسمي لأكاديمية قلب الأسد لكرة القدم للناشئين، من عمر ٥ سنوات فما فوق.

🔗 https://abu00salman.github.io/lionheart


## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | الموقع كاملاً — الهيكل، التصميم، والتفاعل في ملف واحد |
| `logo.png` | شعار الأكاديمية |
| `README.md` | هذا الملف |

## المزايا

- تصميم عربي كامل (RTL) بألوان الأكاديمية: أسود وذهبي مع لمسات بنفسجية ملكية
- زر تبديل بين الوضع الليلي والنهاري (يُحفظ اختيار الزائر تلقائياً)
- عرض للفئات العمرية، خطوات التسجيل، وأسئلة شائعة
- نموذج تسجيل يفتح واتساب مباشرة برسالة جاهزة تحتوي بيانات اللاعب
- متجاوب بالكامل مع الجوال والكمبيوتر

## كيفية النشر على GitHub Pages

1. ارفع الملفين `index.html` و `logo.png` إلى جذر المستودع (Root) — وليس داخل مجلد فرعي.
2. من إعدادات المستودع: **Settings → Pages → Branch: main → / (root) → Save**.
3. بعد دقيقة أو دقيقتين سيصبح الموقع متاحاً على رابط GitHub Pages.

## التعديل

- لتغيير رقم واتساب: ابحث في `index.html` عن `966541977760` واستبدله برقمك (بصيغة دولية بدون + أو أصفار).
- لتغيير الشعار: استبدل ملف `logo.png` بنفس الاسم مع الحفاظ على خلفية شفافة أو داكنة متناسقة.
